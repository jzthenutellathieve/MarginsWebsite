# Field Notes photos

Upload photos for each entry into its own folder here, for example `2025-08-tuas/`.
Use short filenames such as `station.jpg`. The public URL drops `public`:
`public/field-notes/2025-08-tuas/station.jpg` becomes `/field-notes/2025-08-tuas/station.jpg`.

Add or update the matching JSON in `content/field-notes/` with the author, month,
short text, photo paths, dimensions, alt text and captions. Uploading a photo alone
does not publish a note. Run `npm run build` to verify, then commit to deploy.

The August 2025 Tuas entry uses waterfront.jpg, station.jpg and route-map.jpg.
Dates record when the photographs were taken, not a claimed publication date.
